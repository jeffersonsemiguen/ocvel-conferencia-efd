## Lessons Learned

### Técnico
- **`<a href download>` não funciona com endpoints autenticados** — o browser não envia headers customizados. Sempre usar fetch + blob + URL.createObjectURL para endpoints protegidos por JWT. Adicionar `api.download()` ao toolkit padrão do projeto.
- **Endpoint de prévia no router correto** — colocar em `fiscal_periods.py` foi certo: scoped ao `period_id`, evitou router extra. Retornar `efd_file_id` no payload eliminou um request extra do frontend.
- **Conflito de sugestões** — o gerador detecta corretamente 2 sugestões para o mesmo `(line_number, field_index)` e marca como `conflict`. É comportamento intencional de proteção, não bug. O usuário precisa rejeitar uma das sugestões conflitantes para gerar o TXT.

### Processo
- **Build foi o mais limpo da sessão** — 4 arquivos, 0 erros TypeScript, sem surpresas. A fase de design teve padrões de código completos que o build seguiu diretamente.
- **Fix pós-ship** — o bug de download só apareceu ao testar no browser real. Testes manuais de endpoints autenticados devem incluir verificação do header JWT.

### O que funcionou bem
- Reutilizar 100% do `corrected_file_generator.py` existente — zero mudança no gerador validado
- Retornar `efd_file_id` no endpoint de preview eliminou lookup extra no frontend
- TypeScript strict mode pegou 0 erros — tipos bem definidos no DESIGN
